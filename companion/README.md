# A.L.B.E.R.T. phone companion (web fallback)

Legacy browser PWA. Prefer the native iOS app in [`../mobile/`](../mobile/) for TestFlight.

```bash
# from repo root
npm run companion:install
npm run companion:dev
```

Open `http://<your-mac-ip>:5174` on your phone. Pair with the URL/token from Mac **Systems → Phone companion**.
