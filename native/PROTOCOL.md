# Native desktop helper (JSON lines)

One request per stdin line, serialized. Process retains real AX references; terminate to cancel work/clear snapshots. Every response echoes `id`: `{id,ok,result? ,error?:{code,message}}`. All coordinates are global macOS desktop **logical points** (origin top-left, may be negative on secondary screens).

Requests (`op` plus fields):
- `permissions`: no fields. Result `{accessibility,screenRecording}`. Does not request or change grants.
- `list_windows`: no fields. Result `{windows:[{windowId,pid,app,title,bounds:{x,y,width,height},minimized}],displays:[{id,bounds,scaleFactor}],coordinateSpace:"desktop-points"}`. windowId is opaque and session-scoped. It names a real AX reference, not an index. Inventory expires after 60 seconds.
- `inspect_window`: `{windowId}` from inventory. Result `{snapshotId,windowId,pid,app,title,bounds,elements:[{elementId,role,subrole,title,description,value?,enabled,secure,actions:string[],settable,bounds?}],truncated,expiresInMs:60000,coordinateSpace:"desktop-points"}`. Snapshot observes a single window, without focusing it. Secure values never returned. Nodes max 500/depth12; AX message timeout0.1sec and overall traversal budget3sec.
- `focus_window`: `{windowId}` from inventory OR `{snapshotId}`. Result `{focused:true,windowId}` only after focus verified. Invalidates all snapshots.
- `perform_action`: `{snapshotId,elementId,action}`. Action must be in observed list, restricted to AXPress/AXShowMenu/AXConfirm/AXCancel/AXIncrement/AXDecrement/AXRaise/AXPick. Disabled/secure/stale controls rejected. Owner must be frontmost; no hidden implicit focus. Result `{performed:action}`. Refresh after mutation.
- `set_value`: `{snapshotId,elementId,value:string}`. Only editable AXTextField/AXTextArea/AXComboBox, observed settable and enabled, non-secure, max8000UTF16. Owner must be frontmost. Result `{updated:true}`.
- `pointer`: `{snapshotId,kind:"click"|"move"|"scroll"|"drag",x:number,y:number,button?:"left"|"right",clicks?:1|2,deltaX?:number,deltaY?:number,toX?:number,toY?:number,durationMs?:number}`. All points must lie inside live target window bounds AND a connected display. Window must be frontmost. Scroll uses real pixel wheel events at target, deltas [-2000,2000], positive deltaY scrolls content up. Drag max2seconds/default500ms, mouseup guaranteed on ordinary errors and SIGTERM/SIGINT via cancellation flag; parent must send SIGTERM before forced SIGKILL. Result `{performed:kind}`. Every pointer op invalidates snapshots, including move (hover may alter UI).
- `key`: `{snapshotId,key:string,modifiers?:string[]}`. Named keys return/enter,tab,space,escape/esc,delete/backspace,forwarddelete,up,down,left,right,home,end,pageup,pagedown,F1-F12 or one US-layout shortcut character. Modifiers command/cmd,option/alt,control/ctrl,shift. Reject unsupported keys/modifiers; owner frontmost and focused element non-secure and identical to the inspected focused element required. Result `{pressed:key}`.
- `type_text`: `{snapshotId,text:string}` Unicode keyboard events, max8000UTF16, chunks64 units. Owner frontmost, focused non-secure editable text field must match the identity captured at inspection; clipboard unchanged. Result `{typed:characterCount}`.

Mutation success reports native API acceptance only, not downstream task completion. Re-inspect to verify the result. Snapshot IDs expire at60sec and are invalidated after every attempted mutation. Frontmost owner and focused window are verified each time; a moved window is rejected for coordinate actions. Actual AX handles must still belong to the window, retain role/title/identifier fingerprint, and exist in the current app window list; otherwise `stale_snapshot`. Permission failure returns `accessibility_required`. Helper must remain alive across observe/action.

`--self-test` performs only pure parsing/geometry validation; does not read or operate desktop UI.
